## 仍会写入该栏的路径

| 路径 | 当前行为与保护 |
| --- | --- |
| 新建页自动恢复普通草稿 | “新建页”不一定没有旧草稿；可恢复其中原有全称。非空已有值、读取期间修改、版本变化会阻止覆盖。 |
| 错误页初始恢复 | 使用本次提交值；有逐字段修改保护，重置取消恢复，显式选课保留新的课程上下文。 |
| 选择未使用登记 | 用户明确选择后回填该登记的课程字段，包括它本来保存的班级；作废旧草稿 GET 并安排保存。 |
| 普通填表助手确认 | 仅补当前空白字段；用户修改课程字段会使旧请求失效。 |
| 确认现场课程 | 用户明确确认后写入候选快照，再读取新草稿；会采用该候选原有班级名称。 |
| 切换历史照片 | 明确恢复该照片自己的草稿，可能包含历史保存的全称。 |
| OCR／定位／候选查询 | 只更新现场信息或候选展示，不直接回填专业年级。 |

这些“回填已有全称”与“把用户简称转换成全称”需要分开归因。没有当次客户端
事件、赋值栈及操作顺序，不能仅凭最终全称确定来自哪条路径，也不能把问题
归咎于缓存、浏览器或用户操作。
