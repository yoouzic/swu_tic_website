# 审核阶段辅助徽标

用户确认：不新增“小组长已审核”正式状态，在“部门已审核”旁加一枚阶段徽标，区分小组长审核通过和部长审核通过。

- 正式状态机、审核权限、版本链和已阅标记保持不变；`LectureForm.status` 仍是 `待审核 / 部门已审核 / 中心已审核 / 已驳回`。
- 仅当表单状态为“部门已审核”且存在审核人时显示阶段徽标：审核人当前为小组级审核权限时显示“小组长已审核”，部门级显示“部长已审核”。其他状态、无审核人（如历史导入）或审核人无审核权限时不显示。
- 阶段由最新版本审核人的当前审核权限推断，不新增数据库字段。权限变更后历史徽标可能随当前权限重新标注，这是本次采用的轻量取舍。
- 展示位置：审核队列最新行、版本历史行、表单详情（含查看表单与统计页弹窗）、独立审核页。徽标使用浅底描边，避免与正式状态颜色竞争。
- 批量列表通过一次批量权限查询解析审核人权限，避免逐行查询。

验证：隔离 SQLite 覆盖小组/部门/中心/待审核/驳回/无审核人/无权限审核人/多版本标签；确认正式状态、版本链不变；模板契约覆盖队列、审核页和详情页。

上线不需要新增表或迁移；仅代码部署。
