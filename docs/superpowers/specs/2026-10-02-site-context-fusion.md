# 现场线索联合排序与主动提问

用户批准2026-10-02提出的“鲁棒位置误差＋门牌识别＋时间/当前课表联合排序＋主动提问”。定位失败仍允许保存照片、手动选楼。实施仅在已有现场试用开关下生效，最终课程继续人工确认、服务端复验，完整节次来自课表。

模型使用当前权威课表的当天课程全集作为候选。未经人确认的GPS、OCR和时间只影响排序；人确认的楼栋、门牌、节次、教师才作为约束。地理缺失保留中性证据，不剔除课程；不改变课表来源或当前学期。得分与用于计算问题增益的softmax权重均未校准，不展示为正确概率。

位置：保存有界的真实短时采样记录，模型用稳健中心、观测散布、系统误差下限与地图误差估计尺度；不把连续相关采样简单当作独立证据。以建筑区域内归一化取样近似似然，混合窄/宽误差成分保留明显偏移。无定位、校区不匹配、校外或极粗定位降为缺失线索。参数为可替换配置，验证不得宣称真实校准。

门牌：识别整图，再对检测到的独立三/四位数字区域做单行识别；同图各次处理的同一读数取最大分数，不累加票数。保留冲突结果与原始分数，分数只作受限可靠性线索。候选按数字字符相似度与完整教室匹配，不从门牌推断楼栋。旧列表式OCR证据兼容，新结构保存读数、分数和方法。

主动问题：按当前排序权重的预期熵下降与回答成本选择楼栋、房间、节次或教师。最多四种问题，选择过的字段不重复追问。每题提供不确定/都不是/手动入口。课程卡可先显示前三项，但可展开更多。用户明确选择课程后，以该卡的完整教室建立现场上下文，再调用原有确认复验；未确认的模型结果不能自动写入表单。
