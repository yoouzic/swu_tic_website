# 专业年级自动规范实现计划

用户已授权实施。特殊班名和无法唯一对应的专业简称保留，不提醒、不阻止填写；推荐课程独立于各项评价。先更新测试站，正式站等待用户测试反馈。

## 设计

- 用独立格式服务统一明确的四位年级、中文圆括号、师范缩写、两位数字班号、同专业顿号和不同专业分号。
- 专业简称只使用当前学期已选课表批次中的教学班组成与专业组成建立唯一映射，冲突时保持原名。无课表仍可手动填写。
- 原始课表、候选身份和历史记录不批量改写；仅候选展示、确认填写、草稿及新提交规范化。
- 手填输入失焦时调用同一格式服务；返回期间用户修改输入则丢弃旧响应。特殊班名没有提醒。
- 推荐逻辑沿用 f3d9420 已有修复，测试站部署同步获得独立推荐提示。

## 步骤与验证

1. 在隔离工作区增加格式行为测试，确认缺失功能导致失败。
2. 实现格式解析及当前批次专业映射；覆盖特殊班、歧义、幂等性和无课表。
3. 接入候选展示/确认、草稿、新提交与手填失焦；验证候选 ID 和来源未变化。
4. 运行相关 Python 和 JavaScript 回归，检查最终差异。
5. 提交功能分支，更新 test.yoouzic.top；核验测试数据库隔离、HTTPS 行为与移动布局。
6. 记录结果，提供测试账号 test001 至 test010（密码同账号）。正式站暂不部署此功能。

- 240 项 Python 测试、83 个子用例通过；36 项 JavaScript 测试通过。
- 原始课表 18208 行、2395 种班级组成，119 个唯一专业对应；全部格式化结果幂等，原始文件 SHA256 保持 32e9d0744d45ac09fbb5f66548224ea5c735618cc79c5c282c38000644606fc4。
- 审核匹配补充同义班级成员比较，保留旧的文字包含行为；助手班级选项也展示规范文本。
- 测试环境安装 pytest 在主工作区 output 临时目录，未修改服务器或现有 Python 环境依赖。
- 已有 SQLAlchemy Query.get 弃用警告未在本任务中重构。
