## 模型与边界

`app/services/site_context_model.py` 是不依赖Flask/数据库的核心；`ModelParameters` 集中保存可替换的初始参数。所有分数及提问用的softmax权重均**未经校准**，页面只显示匹配理由，不显示正确概率。

### 1. 鲁棒位置

最多保存12条短时真实观察，进入接口时要求时间戳在最近30秒内；保留原坐标与精度，不将计算出的中心伪装成真实测量。客户端仍只把实际观察中的最佳精度点作为主定位。

模型中心为样本经纬度的分别中位数，误差尺度为：

\[
\sigma^2=(r_{95}/2.448)^2+70^2+25^2+s^2,
\qquad s=1.4826\operatorname{median}(d_i).
\]

`r95/2.448` 只是在二维各向同性高斯假设下的尺度近似；70米系统误差下限、25米地图误差和观测散布是初始建模设置，不是实测估计。重复的相关观察不按样本数量缩小误差。有孤立跳点时降低位置证据权重，观测中心不会被单个离群点直接拖走。

建筑使用已缓存的OSM轮廓，加15米门口缓冲，在包围框内做5×5网格积分近似。每栋对有效采样点取平均，避免仅因建筑面积大就天然获得高分。位置似然混合80%窄高斯和20%宽高斯；宽尺度为 `sqrt(sigma²+350²)`。位置比值以0.35为中性参考，未映射楼栋贡献0，保留候选。定位太粗、与已知校园明显不吻合时放弃位置线索。

已明确标为荣昌等其他校区的候选不使用北碚轮廓。目前原有候选DTO没有完整校区字段，工作区荣昌场地保留不同的地点命名；后续补地图/导入新课表时仍需检查楼号与校区对应，不能宣称已经解决所有跨校区同号问题。

### 2. 门牌读数

整图识别后，对检测到的独立三/四位数字区域进行单行识别，绕过第二次文字检测与方向分类。无需人为圈定门牌或使用固定图像位置。每张图最多复核4个数字区域。

同一图片产生的相同读数取最大原始分数，不累加票数；冲突读数一起保留。原有列表式JSON证据兼容，新证据包含 `value/score/method`。原始分数仅用作上限0.85的可靠性线索。按字符编辑距离匹配教室号，6/9、0/8、1/7的替换成本暂为0.6，其他替换为1；这些也不是已经学习到的混淆概率。

门牌似然为 `0.15 + 0.85 × 加权平均(exp(-1.8 × 编辑距离))`，保留不一致的可能。`0609` 和课表 `8-609` 的房间部分规范为609；不能从门牌推断楼栋。人工确认号码后停止用相互冲突的OCR惩罚该号码。

### 3. 时间与联合排序

使用此前用户提供的14节作息。课程包含多个小节时，按各小节的半开区间计算距离，课间采用软衰减；区间结束瞬间标为接近课程，而非仍在上课。

客户端拍摄时间与接收时间相差-5至600秒、日期一致且含时区时，时间可靠性为1；没有拍摄时间时，仅以接收时间为0.6权重线索；明显延迟、日期不符或非法时间不使用该线索。超出14节作息的源记录仍保留，但不臆造时间，课程卡要求手工核对节次。

联合分数：

\[
S(c)=w_g\log\frac{L_g(c)}{0.35}+w_i\log L_i(c)+w_t\log L_t(c).
\]

初始权重为位置0.9、门牌2.7、时间1.5，另乘各自的可靠性。课表提供当天合法候选全集，未另加一份同义“课表匹配分”，避免重复计入相同证据。人工确认的楼栋、门牌、节次、教师形成约束；未经确认的GPS、OCR和时间只排序，不硬排除课程。

### 4. 主动问题与人工确认

图像产生互相冲突的号码时先展示这些实际读数，例如 `6090 / 0609`。没有冲突时，在合理的物理教室候选上比较问题的预期熵下降/回答成本，选择楼栋、房间、节次或教师；线上课程不会作为“门牌号”选项。用于提问的权重不是校准概率。

最多四种问题，已回答的字段不重复问。可选择“不确定，直接看课程”“都不是，手动修改”，课程卡先展示前三项，仍能展开其他候选。

点击具体课程卡才会以该卡的完整教室建立现场上下文，再调用原有服务端确认复验。完整起止节次来自课表，评价、学生姓名电话不由模型编造。提问中尚未确认成课程的答案为页面临时状态；刷新后需要重新选择，照片与已确认课程/评价草稿仍按原规则保存。

异步状态保护覆盖记录切换、答案修改和确认期间的晚到响应。独立审查发现并修复了Find期间修改门牌的竞态：查找未结束时锁定教室输入与助手选项，释放时保留仍在进行的确认锁。

## 配对模拟回放

输入为工作区唯一课表 `2025-2026-2全校课表260413.xlsx`，SHA256 `6783ef7433f3839eea78894ec869fc297cd77f47313cbaaa34e569c7d3f00790`。教学周6、第一周周一2026-03-02与现有隔离配置一致。模型不接收目标课程、教师、班级答案；这些只作为独立真值，或在模型确实提出该问题后提供模拟人工回答。

基线是明确构造的“附近楼栋距离＋最高分OCR号码精确匹配＋小节排序”，不是原助手真实用户完成率。第一组60条目标课程，每条5类输入，共300场景；定位、OCR冲突和拍照时段都是模拟注入。

| 场景，每类60个 | 基线课程Top3 | 联合课程Top3 |
|---|---:|---:|
| 清晰、正常位置 | 96.7% | 96.7% |
| 偏到另一栋楼 | 85.0% | 81.7% |
| OCR出现冲突读数 | 0.0% | 90.0% |
| 没有定位 | 53.3% | 53.3% |
| 课间拍照 | 53.3% | 96.7% |
| 合计 | 57.7% | 83.7% |

加入模拟正确回答后，目标进入Top3为99.7%。回放一旦知道目标已在Top3就停止追问，这是理想的模拟识别条件，不能当作真实人工完成率、平均实际题数或正确自动填表率。偏移场景还有1个目标未进入Top3，仍须更多候选/手动路径。

第二个种子20261003选40条目标、200场景，基线67.0%、联合91.5%，偏移场景87.5%→85.0%，模拟回答后99.5%。这是另一个随机种子复核，来源候选与第一组可能重叠，没有训练/测试独立划分，文件名 `holdout-replay.json` 不代表严格留出验证。

结果表明改善主要来自OCR冲突保留和课间软时间；单独定位偏移尚未稳超基线。没有宣称实测准确率、地理校准或生产验收。
