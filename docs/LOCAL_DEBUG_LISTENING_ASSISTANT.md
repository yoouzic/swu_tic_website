# 听课助手本地测试

双击项目根目录的“本地调试.cmd”。未运行时选1启动；已有服务时选3重启以加载新代码。默认地址为 http://127.0.0.1:5087。

启动器会准备隔离测试库、三个测试账号，导入工作区的 `2025-2026-2全校课表260413.xlsx`，将其配置为唯一的当前课表，并创建听课助手索引。同一文件再次启动只复用，不重复导入。原课表文件和正式业务数据库不修改。

| 账号 | 用途 | 密码 |
|---|---|---|
| user001 | 信息员填表 | 1234564 |
| manager | 管理员 | 1234564 |
| super | 后台配置 | 1234564 |

用信息员账号测试：选择授课教师，输入“王越”，再选2026-04-07。可选择“形势与政策 · 王越 · 38-508 · 第7-9节”，确认后基础信息会填入；仍需本人填写评价和见证人。测试课表是上一学期的数据，不能拿当前日期查询它并据此判断匹配功能失效。

学期由后台配置，信息员无需输入。听课助手仅使用当前课表，不显示备用课表或来源批次。浏览器旧学期不会切换查询范围；旧课表的确认信息失效时保留手填内容，重新选择课程。

替换测试课表时，可用 `LOCAL_DEBUG_SCHEDULE_FILE` 指定另一份单学期Excel。新学期需用 `LOCAL_DEBUG_FIRST_WEEK_MONDAY` 提供对应教学日历的第一周周一（YYYY-MM-DD）；当前工作区提供的测试学期自动使用已核验的2026-03-02。缺少文件、多学期混表或没有有效听课索引时，启动会明确失败，不伪造课表。

默认测试库：`data/instance/debug/lecture_forms-debug.db`。开发验证可通过 `LOCAL_DEBUG_RUNTIME_ROOT`、`LOCAL_DEBUG_STORAGE_ROOT`、`LOCAL_DEBUG_PORT` 设置另一个隔离目录和端口。


## 现场拍照试用（2026-10-02）

本地启动器会开启 `LECTURE_CAPTURE_ENABLED=true`，初始化只属于隔离库的新记录表。生产默认关闭；开启前在部署环境安装 `requirements-capture.txt` 并初始化 `LectureSiteCapture` 的附加表（可在应用上下文调用 `app.services.lecture_site_capture.ensure_capture_schema()`）。不要将本地测试开关误当作正式上线。

信息员入口新增“现场听课记录”：相机拍门牌、选择楼栋、查找并确认课程；每次记录单独保存照片、时间、定位和草稿。可记录另一节课，再从“待补完记录”恢复各自评价。拒绝定位仍可保存；相机权限拒绝给出重试提示。图片仅本人可访问，提交后仍关联表单保存。

拍照推算的小节只影响候选的优先展示，不自动决定整门课起止节次。确认3–4节课程后，哪怕在第4节拍照，也填3–4。时间配置依据用户提供的14节截图，课间不猜节次。暂无楼栋坐标，因此楼栋需人工核对，不宣称自动定位成功。

本地当前课表仍为2025-2026-2。今天2026-10-02的照片正常找不到该春季课表的课程：应保存为待确认，不能为了演示匹配而篡改现场日期或偷偷替换课表。课程确认闭环已用隔离测试课表验证。

手机网页相机需安全上下文（HTTPS）；本机localhost适合桌面试用。局域网普通HTTP不能作为手机实机通过的证据。门牌OCR在本地处理，生成的601/308/1001照片仅验证管道，实际反光/斜拍/模糊门牌准确率待实拍测试。
