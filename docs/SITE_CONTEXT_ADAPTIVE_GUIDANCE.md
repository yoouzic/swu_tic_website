# 就近推荐与按需澄清：落地验证

2026-10-02。本轮承接用户反馈“远处同门牌课程不应默认推荐”，实现：明确时直接推荐，证据不足时最多补问两次，仍不确定则扩大范围。继续保留最终人工课程确认。

## 实际交互

- 原演示记录：定位模拟落在25教，照片为0609。默认仅展示约191米外的8教609；约935米的38教609、约1182米的32教609只在主动扩围后展示，并标出距离与范围扩大提示。不凑满三项。
- 无定位但照片与时间有效：先问“你在哪栋教学楼？”，只给有候选支撑的8/32/38教。回答8教后直接给出8教609课程，不再继续问门牌、教师。
- 不知道楼栋时可以跳过，改问教师等其他可区分线索；最多两问。仍不确定就停止追问，显示扩围与修改信息入口。
- 同一教室、同一完整节次只剩两三门课程时，直接核对课程卡，不先多问一遍教师。
- “不确定”不成为事实；修改答案不重置已用问题数。显式重新开始、切换记录或刷新页面会开启新一轮；问题状态没有持久化到数据库。
- 无定位且OCR失败，不把全日课表前三项称为可靠推荐，保留照片并进入扩围/手动路径。

## 实现与初始参数

`site_context_model.py`保留完整候选排序，`site_context_guidance.py`独立决定展示和提问。候选全集不会因地理距离、OCR或时间推测而被删除；人工确认的事实才限制搜索。

- 有可用地图证据、位置可靠度不低于0.5且没有跳点时，默认优先范围为 `max(250米, 报告精度 + 50米)`。该范围不是现场校准的置信区间。
- 默认课程需要门牌支持，以及时间或已确认信息支持；门牌近似、时间冲突等进入澄清。OCR原始分数0.65仅作初始筛选线索，不解释为65%正确率。
- 同一可用范围内考察领先差距；0.7为当前未校准的匹配分差阈值。它与位置、门牌、时间的绝对支持共同使用，不能单独把低分第一名变成可靠推荐。
- 问题最多6个候选选项，答案来自实际课表候选；默认最多2问。不会因无法生成简短问题或用户跳过唯一判别字段，就宣称已解决歧义。
- 人工确认楼栋可以覆盖GPS范围，课程卡显示“楼栋已由你确认”；未映射楼栋始终可以在扩围/手动入口找回。
- API参数`question_count`拒绝负数、布尔值、字符串及大于2的值。候选确认仍经原服务端权威课表复验。

## 追加：不知道、跳过与返回

用户随后指出原填表助手缺少“不知道/跳过”，本轮一并修复：

- 原课程引导新增“我不知道，跳过此题”和随时手动填写。跳过当前事实后保留已有事实，改问尚未询问的维度；原引导仍沿用最多4个事实问题的上限。初始都不记得、候选无法选定或全部跳过时，提供稍后补充/手动填写出口。
- 跳过记录只进入交互历史，不成为查询事实。输入框直接键入“我不知道/跳过此题”也不会被当作教师或教室名称。
- 返回采用当前轮的前一状态，恢复原问题并撤回后续回答；不再用缺少跳过信息的事实集合重建问题。恢复出的选项最终仍经服务端复验。
- 修复实页发现的返回按钮问题：请求结束恢复旧控件状态时，曾把刚变为可用的返回按钮再次禁用；现在按当前历史计算可用性。
- 修复初始记忆类别错位：页面显示“日期/教师/教室”时，不再把点击A误应用到服务器根据旧表单事实生成的另一道问题。
- 现场补问统一显示“我不知道，跳过此题”，增加返回上一题。返回恢复前一步事实、已问字段与当前路径计数；同时清除已撤回的楼栋输入。主动回退重答是人工纠错，自动向前仍最多两问。
- 评价中的“有无变化/异常”和“是否推荐”均可稍后回答，推荐问题可返回前一题。跳过不自动填“无/不推荐”，也不清掉人工已有答案；未填的必填项进入待补充清单，原提交校验不变。

实际页面验证：原引导“日期跳过→教师→返回日期”成功；四个事实问题全部跳过后，服务端`known_facts={}`、`question_count=4`、`stage=manual`。评价两题跳过后，变化/异常/建议/推荐四字段仍为空，显示待补充13项。现场问题跳过后可返回，再选8教后也可返回楼栋问题，撤回的楼栋输入为空。
