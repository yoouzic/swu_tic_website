## 50 字口径

阈值保留为至少 50 字。计入中文及其他 Unicode 字母、数字；标点、空白、
符号、表情不计入，组合音符不额外增加字数。数字键帽表情也不作为数字计算。
原文不因字数校验而被删改。

`feedback_text.py` 与 `feedback-text.js` 提供一致的计数语义，接入提交与审核编辑
校验、原自动审核、新规则引擎、填写页计数器、补全助手和审核页。页面明确提示
标点不计数，修改过的脚本更新缓存版本。保留旧表单未修改内容的既有兼容规则，
不批量修改历史数据或重算扣分。

## 真实导出对账

对线上标准表及全字段表执行共 8 次下载，覆盖全部、已审核及批量选择范围。
每次请求前后读取数据库指纹，确认核对期间没有数据变动：

- 全部范围：693 张最终表单；
- 已审核范围：650 张；
- 批量选择：166 个物理版本归并为 30 张最终表单。

导出数量、最终 ID、字段、12/33 列结构及标准表合并单元格均通过核对。
综合统计只纳入在任成员，因此与全量历史导出相差 1 张离任成员的最终表单，
不是漏导。导出游标在只读核查中保持不变。

发现并修复的导出边界：

1. “=”开头的用户文字可能被 Excel 识别为公式。现显式写为文本，值不加额外引号；
   同时验证 `+`、`-`、`@`、`#N/A`、`#REF!` 等原文按文本保存。
2. 混合日期显示格式曾按字符串排序，现解析日期排序。
3. 文件序列化失败曾提前推进增量游标，现成功生成响应后才推进。
4. Windows XML 写入可能将 CRLF 变成额外空行。仅在导出中统一 CRLF/CR 为 LF，
   保留原有空行与正文，不修改数据库。线上仅一条记录存在这种换行表示差异，
   统一换行后所有字段完全一致，没有正文丢失。

隔离库回归同时覆盖全部/选中/增量范围与两种导出模式、32 版本长链、旧状态、
同人同周多课、空/零逻辑 ID、前导零、公式样式文字、多行内容及失败重试。
真实生产库不调用会推进游标的增量下载。
