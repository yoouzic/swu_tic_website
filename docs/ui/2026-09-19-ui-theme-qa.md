# 2026-09-19 主题页面验收与修复

基于 `3007499` 的交接继续验收，保留已确认的纸白、墨蓝灰与旧金配色。全部浏览器操作使用新建的临时 SQLite 和合成账号；未使用业务库、备份库或正式服务。

## 已修复

1. **卡片标题背景凸出圆角**：Chrome 现场测得卡片圆角 18px，Bootstrap 5.1 标题圆角 3px。标题、页脚现在继承实际父卡片圆角，折叠部门标题同时继承下边角；不设置 `overflow: hidden`，避免裁切部门、小组和用户下拉菜单。无圆角的扁平卡片仍继承零圆角。
2. **手机导航跨断点后锁住正文**：390px 打开导航再拉宽到 1440px，正文仍为 `inert`。现在监听与 CSS 一致的 959px 媒体查询，离开移动布局时关闭抽屉并解除背景与滚动锁定。

3. **自动审核状态徽标白字浅底**：原模板及动态更新使用 Bootstrap 5.2 的 `text-bg-*`，本地 5.1 无对应背景。改为已有的 `bg-secondary` / `bg-success`，真实浏览器验证初始及就绪状态对比度均至少 4.5:1。
4. **用户菜单 Escape 关闭丢失焦点**：Bootstrap 5.1 关闭后焦点留在隐藏链接。仅在焦点仍属于用户菜单时恢复到触发按钮，避免鼠标点击外部输入框时抢焦点。

四项均有修复前失败、修复后通过的回归证据。卡片用真实 Chromium 计算样式测试，导航和菜单用状态测试并补真实浏览器复测；徽标测试从真实模板和 JS 提取类名后交给浏览器计算。
