# 教学楼模型与地图对应核查

## 当前交付范围

2025-2026-2 当前课表的 30 个数字教学楼中，23 个已接入地图轮廓；另 7 个仍只提供外观参考，不放置猜测坐标。F、G、MC1、MC2、99 按用户要求忽略。

- 已对应：1、4（A栋）、5、7、8、10、11、14、15、23、24、25、27、28、30、31、32、33、35、37、38、39、40。
- 待核对：3、6、9、16、17、19、48。4B 也不能沿用 4A 的轮廓。
- 这是公开地图和校方资料的文献对应，不是实测定位。模型高度、遮挡面和外观比例仍为简化示意。

## 对应证据与导入

新增 10 个有名称的 OSM 建筑采用 `app/data/swu_building_correspondences.json` 白名单；记录对象 ID、预期名称、校方楼宇资料和总图链接、判断依据。导入时名称改变或与显式楼号冲突会报错，不按学院名称模糊匹配。

另补入 OSM relation 11548065（30教）和 11546904（31教）。导入器拼接多段轮廓，保留庭院内环；前端用 evenodd 路径展示，后端距离计算不再把庭院当作楼内。底座和模型共用地理投影与轮廓方向，选中后居中并突出标记。

复现：

```powershell
.venv-audit/Scripts/python.exe tools/build_campus_buildings.py output/2026-10-02-campus-building-mapping/osm-campus-raw.xml --correspondences app/data/swu_building_correspondences.json
```

数据共 26 个轮廓，其中 22、26、29 不属于当前课表，选楼列表按当前课表过滤。读取的是保存的 OSM 快照，生成时间不等于地图测绘或更新时间。

## 新旧编号冲突

- [音乐学院命名说明](https://music.swu.edu.cn/info/1032/4253.htm)：原16教、原19教合并命名为现19教厚乐楼 A、B 栋。当前课表16教的21条记录为音乐课程。现16号求实楼的照片模型不能用来辨认这些教室。
- OSM 音乐学院对象 843421759 尚不足以确认具体 A/B 轮廓，因此撤回试配的19教位置，不把 A/B 任一模型强行贴在整个学院轮廓上。
- 48教课表包含纺织实验教室；现48号弘新楼的工程技术学院资料不能单独证明两者相同，继续保留未定位状态。
- 3教存在前、后楼及不同学院用楼；6、9、17尚未找到足以唯一对应地理轮廓的依据。

相关模型详情增加课表编号与当前官网编号的差异说明，避免外观参考被误当成定位证明。

参考：[学校楼宇目录](https://www.swu.edu.cn/whxd/hjwh/ly.htm)、[校方北碚总图](https://120th.swu.edu.cn/xyhj/xydt.htm)、[2023新生地图](https://ai.swu.edu.cn/info/1099/2492.htm)。校方示意图没有地理配准参数，不能直接当经纬度数据。
